## Projects

### [Activity Explorer](https://github.com/Peter537/activity-explorer)

A local-first, open-source Blazor application for exploring cycling, running,
and walking history from Garmin and Strava exports without provider credentials.

**Highlights**

- Imports Garmin and Strava exports plus FIT, GPX, TCX, GZ, and ZIP files.
- Provides searchable activities, sensor charts, records, routes, segments, and maps.
- Keeps activity data local with deduplication, provenance tracking, and profile support.
- Tech: C#, .NET 10, Blazor, Entity Framework Core, SQLite, Docker.

---

### [Holdet Fantasy Hub](https://github.com/Peter537/holdet-fantasy-hub)

An unofficial, local Windows dashboard for exploring public Holdet.dk fantasy
data across games, players, teams, managers, seasons, groups, and tournaments.

**Highlights**

- Provides round dashboards, player and team statistics, watchlists, comparisons, and exports.
- Tracks manager careers, rankings, records, streaks, and head-to-head results.
- Supports custom seasons and league, Swiss-system, knockout, and double-elimination tournaments.
- Tech: Python 3.14, Streamlit, Starlette, XlsxWriter.
